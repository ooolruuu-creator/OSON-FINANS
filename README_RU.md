# OSON FINANS — Android

Отдельное Android-приложение для учёта доходов и расходов в UZS.

- Отдельный applicationId: `uz.osonfinans.app`; отдельная БД `oson_finans.db`; старое приложение «Мои деньги» и его данные не затрагиваются.
- Иконка приложения — предоставленный логотип OSON FINANS.
- История: поиск, фильтры «Сегодня / 7 дней / Месяц / Всё / Дата», календарь, группировка по дням, итоги и расходы по категориям.
- Лимиты: зелёный ниже 70%; оранжевый от 70% до 100%; красный выше 100%; короткая вибрация при первом превышении.
- Голосовой ввод: русский, узбекский, английский, китайский, немецкий, хинди, испанский, французский, арабский.
- Кнопка проверки обновлений открывает страницу GitHub Releases.

## Сборка
Откройте проект в Android Studio или загрузите содержимое в отдельный GitHub-репозиторий и запустите Actions → Build OSON FINANS APK. Локальная команда: `gradle assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Обновления
Ссылка в приложении: `https://github.com/ooolruuu-creator/OSON-FINANS/releases/latest`. Создайте отдельный репозиторий `OSON-FINANS`. Workflow публикует собранный APK в GitHub Releases; кнопка в приложении открывает страницу последнего релиза.

Важно: Android разрешит установку обновления поверх старой версии только если APK подписаны одним и тем же постоянным ключом. Текущий workflow создаёт debug APK; для стабильных обновлений настройте постоянный signing keystore через GitHub Actions Secrets до первой установки и используйте один ключ для всех будущих релизов. Проверка в приложении пока открывает страницу релизов; автоматической установки нет.

Голосовое распознавание использует системную службу Android. Поддержка языков и офлайн-режим зависят от телефона и языковых пакетов. Всегда проверяйте распознанную сумму и категорию до сохранения.
